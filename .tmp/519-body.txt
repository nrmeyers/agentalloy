Execution index for the open backlog. Written to be picked up cold.

**How to use this:** work top to bottom within a track. Tracks are independent.
Each entry gives the blocking relation and the *first concrete action*.

**Order is enforced by native GitHub issue dependencies**, not just by this
document. Each blocked issue lists its blockers in its own sidebar, and GitHub
will not let you close one out of order without telling you. To ask the repo
what is actionable right now — no reading required:

```bash
for n in $(gh issue list --state open --limit 50 --json number --jq '.[].number'); do
  b=$(gh api repos/nrmeyers/agentalloy/issues/$n/dependencies/blocked_by --jq '[.[].number]|join(",")')
  [ -z "$b" ] && echo "#$n actionable" || echo "#$n blocked by $b"
done
```

If this document and the dependency graph ever disagree, **the graph wins** —
it is the thing that can't go stale silently.

**Labels:** exactly one `status:` per issue — `status:ready` (start now) ·
`status:needs-verification` (confirm the repro before writing code) ·
`status:blocked` (a listed issue must land first) · `status:deferred` (parked).

## Cross-cutting theme worth one convention

Three issues are the same defect: **a best-effort fallback that is correct for an
absent resource and destructive for an unreachable one**, failing silently in the
harmful direction.

| | Returns | On unreachable |
|---|---|---|
| `read_upstream` (#531) | `None` — **fixed in #537** | routed to the wrong upstream |
| `read_flow_state` (#530) | `"workflow"` — **fixed in #533** | failed closed on write access |
| `_collect_store_design_chunks` (#526) | `[]` — **guarded in #534** | deleted decision edges |

All three now have point fixes. **The convention does not exist yet** — a shared
`StateUnavailable`, the absent-vs-unavailable rule as a stated rule, and an
*unreachable* test alongside every *absent* test. That is what stops the fourth
instance being written, and it is the residual scope on #531. Same root as the
merged lesson in `docs/solutions/add-telemetry.md`: a degraded path that returns
the shape of success.

A *related but distinct* family, do not conflate: derived state that fails to
follow its source — #535 (posture does not follow `phase set`) and #520 (the
cycle-end sweep does not archive store contracts). Different mechanism, different
fix.
